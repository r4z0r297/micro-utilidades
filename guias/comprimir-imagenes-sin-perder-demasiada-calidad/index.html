Cómo comprimir imágenes sin perder demasiada calidad

Aprende a elegir formato, dimensiones y nivel de compresión para reducir el peso de una imagen sin estropearla.

La idea principal

Una guía práctica para web, trabajos académicos y archivos compartidos. No necesitas memorizarlo todo de golpe: empieza por el procedimiento básico, prueba un caso sencillo y después utiliza la herramienta para comprobar el resultado.

Formato según el contenido

JPEG suele ser apropiado para fotografías. PNG resulta útil cuando necesitas transparencia o gráficos con bordes definidos. WebP y AVIF pueden ofrecer una buena relación entre calidad y tamaño en entornos compatibles. La elección depende del destino final.

Dimensiones importan tanto como la compresión

Una fotografía de 6000 × 4000 píxeles puede pesar mucho aunque utilices una compresión razonable. Si la imagen se va a mostrar en una página a 1200 píxeles de ancho, conservar seis mil píxeles puede ser innecesario.

Cómo revisar calidad

No te fijes únicamente en el tamaño del archivo. Amplía zonas con texto pequeño, líneas finas, caras y degradados. Si aparecen bloques, halos o pérdida de detalle, reduce menos la calidad o cambia de formato.

Para trabajos y webs

Para un trabajo académico, prioriza legibilidad. Para una web, además del aspecto visual importa el tiempo de carga. Guarda una copia original antes de comprimir si el archivo puede volver a editarse.

Preguntas frecuentes

¿PNG siempre tiene mejor calidad?

No es una comparación tan simple. PNG utiliza compresión sin pérdida, pero puede generar archivos grandes en fotografías.

¿Debo comprimir una imagen ya pequeña?

Solo si existe una razón. Si pesa poco y se ve bien, volver a comprimirla puede aportar poco y degradarla.

¿Qué formato es mejor para una web?

Depende del navegador, contenido y requisitos. WebP y AVIF suelen ser buenas opciones modernas, mientras JPEG y PNG siguen siendo muy compatibles.
