La idea principal

Una guía pensada para prácticas de redes y FP: primero entiendes el procedimiento y después utilizas la herramienta como comprobación. No necesitas memorizarlo todo de golpe: empieza por el procedimiento básico, prueba un caso sencillo y después utiliza la herramienta para comprobar el resultado.

Qué significa 192.168.1.34/24

El número después de la barra es el prefijo CIDR. En /24 hay 24 bits dedicados a la red y 8 bits para hosts. La máscara equivalente es 255.255.255.0. Para la IP 192.168.1.34, la dirección de red es 192.168.1.0 y el broadcast es 192.168.1.255. En una red IPv4 convencional /24 quedan 254 direcciones utilizables para hosts.

Cómo pasar de una red a varias subredes

Si necesitas dividir una /24 en cuatro redes iguales, puedes aumentar el prefijo a /26. Al tomar dos bits adicionales para la red aparecen 2² = 4 subredes. Cada /26 contiene 64 direcciones totales y normalmente 62 hosts utilizables. Los bloques empiezan en 0, 64, 128 y 192 en el último octeto.

Errores habituales

Uno de los errores más frecuentes es confundir la IP de un equipo con la dirección de red. Otro es contar el broadcast como host disponible. También conviene comprobar que el prefijo está entre /0 y /32 y que la dirección IPv4 tiene cuatro octetos válidos. En ejercicios de clase, escribe siempre IP, máscara, red, broadcast y rango para poder revisar el procedimiento.

Preguntas frecuentes

¿/24 significa 24 hosts?

No. /24 indica que 24 de los 32 bits de IPv4 pertenecen al prefijo de red. Quedan 8 bits para hosts.

¿Cuál es el broadcast de 192.168.1.0/24?

192.168.1.255. Las direcciones normalmente utilizables para hosts van de 192.168.1.1 a 192.168.1.254.

¿Para qué sirve CIDR?

Permite expresar el tamaño del prefijo de red de forma compacta y facilita dividir y resumir redes.
