Cómo preparar un PDF para entregar un trabajo

Comprueba tamaño, páginas, orientación, legibilidad y nombre del archivo antes de entregar un documento en PDF.

La idea principal

Una lista práctica para evitar errores habituales al enviar trabajos, apuntes o documentación. No necesitas memorizarlo todo de golpe: empieza por el procedimiento básico, prueba un caso sencillo y después utiliza la herramienta para comprobar el resultado.

Antes de comprimir

La compresión no debe ser el primer paso. Primero comprueba que el PDF está completo y se visualiza correctamente. Si contiene capturas o imágenes, revisa especialmente que el texto pequeño siga siendo legible.

Tamaño frente a calidad

Reducir el tamaño puede ser útil cuando una plataforma de entrega tiene un límite, pero una compresión demasiado agresiva puede degradar imágenes y capturas. Si el límite es, por ejemplo, 10 MB y tu documento pesa 3 MB, no necesitas comprimirlo simplemente porque exista la opción.

Nombre y organización

Utiliza nombres como «UT2_Redes_AlbertoGarcia.pdf» en lugar de «documento_final_final2.pdf». Si el profesor ha establecido una nomenclatura concreta, esa indicación tiene prioridad.

Privacidad

Antes de subir un documento, comprueba si contiene datos personales, comentarios, metadatos o información que no debería compartir. Una herramienta de compresión puede procesar el archivo localmente o utilizar recursos externos según su implementación; revisa la información de privacidad de la herramienta concreta.

Antes de empezar
Identifica los datos, las unidades y el resultado que necesitas obtener.
Después de calcular
Revisa el resultado con un ejemplo conocido antes de utilizarlo en una tarea importante.

Preguntas frecuentes

¿Es necesario comprimir todos los PDF?

No. Solo tiene sentido si necesitas reducir el tamaño o cumplir un límite de subida.

¿La compresión puede borrar texto?

Una compresión correcta no debería eliminar el contenido intencionadamente, pero puede reducir la calidad de imágenes o escaneos.

¿Qué formato debo entregar?

El que indique la actividad. Si piden PDF, evita cambiarlo a otro formato solo para reducir tamaño.
