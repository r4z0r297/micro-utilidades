JSON: cómo validar, leer y corregir un archivo

Aprende las reglas básicas de JSON, los errores más comunes y un método sencillo para localizar problemas de sintaxis.

La idea principal

Una guía práctica para trabajar con JSON sin limitarse a comprobar si el texto es válido. No necesitas memorizarlo todo de golpe: empieza por el procedimiento básico, prueba un caso sencillo y después utiliza la herramienta para comprobar el resultado.

La estructura básica

Un objeto JSON utiliza llaves y pares clave-valor. Por ejemplo: {"nombre":"Ana","edad":20}. Las claves son cadenas entre comillas dobles. Los valores pueden ser cadenas, números, booleanos, null, objetos o arrays. JSON no utiliza comentarios como parte de su sintaxis estándar.

Errores que aparecen continuamente

Un error típico es escribir comillas simples en lugar de dobles. Otro es olvidar una coma entre dos propiedades: {"nombre":"Ana" "edad":20}. También es habitual cerrar una llave o corchete antes de tiempo. Cuando el archivo es grande, formatearlo después de validarlo ayuda a ver qué nivel de la estructura está mal.

JSON y APIs

JSON se utiliza con frecuencia para intercambiar datos entre aplicaciones y APIs. Validar el cuerpo de una petición antes de enviarlo puede ahorrar tiempo al depurar. Si un servidor responde con un error, comprueba primero nombres de propiedades, tipos de datos y estructura esperada por la API.

Método de comprobación

Pega primero un ejemplo pequeño y válido. Después añade una propiedad cada vez. Si el documento deja de validar, el último cambio suele ser el punto de partida para localizar el problema. En AppQuickUtils puedes validar y formatear el JSON sin instalar un editor específico.

Preguntas frecuentes

¿JSON permite comentarios?

El estándar JSON no define comentarios. Algunos programas aceptan extensiones, pero no debes asumir que una API los admitirá.

¿Las claves pueden llevar comillas simples?

En JSON estándar deben utilizarse comillas dobles.

¿Validar JSON significa que los datos son correctos?

Solo comprueba la sintaxis. Un JSON puede ser válido y aun así no cumplir el formato que espera una aplicación.
